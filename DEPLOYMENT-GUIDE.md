# 🚀 Website Deployment Guide - Bungash Designs

## Sabse Aasan Tareeqa - Netlify Drop (Recommended)

### Step 1: Website Ko Folder Mein Ready Karein
✅ Already ready hai! Ye teen files chahiye:
- `index.html`
- `style.css`
- `script.js`

### Step 2: Netlify Drop Use Karein

1. **Browser mein jayen:**
   ```
   https://app.netlify.com/drop
   ```

2. **Drag & Drop:**
   - C:\Bangash folder ko browser window mein drag karein
   - Ya "browse to upload" click karke files select karein

3. **Done!**
   - Instantly deploy hojayega
   - Aapko ek link milega: `https://random-name-12345.netlify.app`
   - Ye link client ko bhej sakte hain

### Link Customize (Optional):
- Netlify dashboard mein jayen
- "Site settings" → "Change site name"
- Example: `bungash-designs.netlify.app`

## Alternative Option 2: Surge (Command Line - If NPM Installed)

### Agar Node.js installed hai:

```powershell
# Install Surge globally
npm install -g surge

# Deploy karo
cd C:\Bangash
surge
```

- Email enter karein (first time)
- Password set karein
- Domain name: Press Enter (random milega) ya custom type karein
- Done! Link mil jayega

---

## Alternative Option 3: GitHub Pages (Free Forever)

### Agar GitHub account hai:

1. **GitHub pe new repository banao**
   - Repository name: `bungash-designs`
   - Public rakhein

2. **Files upload karein:**
   - "Add file" → "Upload files"
   - Teen files select karein (index.html, style.css, script.js)
   - Commit karein

3. **GitHub Pages enable karein:**
   - Settings → Pages
   - Source: "main branch"
   - Save

4. **Link milega:**
   ```
   https://your-username.github.io/bungash-designs
   ```
