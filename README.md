# Bungash Designs - Premium Interior Solutions

## 🎨 Project Overview

This is a **professional, high-end website** designed for Bungash Designs - a premium interior design company based in Defence, Karachi. Built with modern web technologies including HTML5, CSS3, JavaScript, and GSAP animations to create an impressive, interactive user experience.

## ✨ Features

### Design & UX
- **Modern, Clean Design** - Professional layout inspired by premium brands
- **Smooth Animations** - GSAP-powered scroll animations and transitions
- **Custom Cursor** - Interactive cursor for desktop users
- **Responsive Design** - Fully responsive across all devices
- **Loading Screen** - Elegant preloader animation

### Sections
1. **Hero Section** - Eye-catching hero with animated statistics
2. **About Section** - Company information with floating cards
3. **Features Section** - Detailed product features with visual elements
4. **Products Gallery** - Filterable product showcase with 150+ colors
5. **Image Gallery** - Stunning project gallery with hover effects
6. **Testimonials** - Customer reviews slider
7. **CTA Section** - Call-to-action with gradient background
8. **Contact Form** - Professional contact section
9. **Footer** - Comprehensive footer with newsletter subscription

### Animations & Interactions
- Smooth scroll animations using GSAP ScrollTrigger
- Parallax effects on images and backgrounds
- Magnetic button effects
- Counter animations
- Product filter animations
- Custom ripple effects on buttons
- Image lazy loading with fade-in
- Scroll progress indicator

## 🚀 Technologies Used

- **HTML5** - Semantic, accessible markup
- **CSS3** - Modern styling with CSS Grid, Flexbox, and custom properties
- **JavaScript (ES6+)** - Modern JavaScript features
- **GSAP 3.12.4** - Professional-grade animation library
  - ScrollTrigger plugin
  - ScrollToPlugin
- **Google Fonts** - Montserrat & Playfair Display
- **Unsplash Images** - High-quality placeholder images

## 💻 How to Use

1. **Open the Project**
   - Open `index.html` in any modern web browser
   - For best experience, use Chrome, Firefox, or Edge

2. **Local Development**
   ```bash
   # Simply open index.html in your browser
   # Or use a local server like:
   npx serve
   # or
   python -m http.server 8000
   ```

3. **Customization**
   - Update images in HTML (replace Unsplash URLs)
   - Modify colors in `:root` CSS variables
   - Adjust animations in `script.js`
   - Change content in HTML sections
